# Project discontinued

`dsh-codex-session-sync@0.4.0` is deprecated and removed from the active DSH profile.

- The historical alpha.1 migration remains documented and its backups remain valid.
- No new synchronization runs should be started from DSH.
- The GitHub repository is archived read-only after this notice is pushed.
- The plugin is excluded from the next Maintenance Generation.

This retirement does not delete imported DSH sessions, Codex source sessions, migration backups, or the external ledger.
